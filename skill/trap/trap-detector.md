# 杀猪盘检测 · 8 信号工作流

触发词：朋友推荐 / 群里说 / 老师带 / 内幕消息 / 必涨 / 翻倍 / 稳赚 / 跟单 / 小红书(抖音)看到。
显式触发：「这票安全吗」「是不是杀猪盘」。

## 流程
1. 先跑数据：`python3 scripts/fetch.py all <代码>`
2. 逐项扫 8 信号（每项给 命中/未命中/无法判断 + 证据）：
   ① 推荐前已大幅拉升（kline.summary.pct_3d 或 20 日涨幅异常）
   ② 人气热度与基本面脱节（sentiment.grade 高 + fund 营收平庸）
   ③ 龙虎榜异常席位对倒（lhb 买卖额接近、同营业部进出）
   ④ 低质账号集中推荐（联网搜索「<名称> 推荐」看同质化文案）
   ⑤ 话术模板化（搜「<名称> 即将爆发 / 主力建仓完毕 / 目标翻倍」）
   ⑥ 付费群/VIP直播间引流（搜「<名称> 微信群 / 直播间 / VIP」）
   ⑦ 老师/股神人设（搜「<名称> 老师 / 股神」）
   ⑧ 流通市值小 + 换手异常（fund.float_mcap_yi < 50 且 quote.turnover_pct > 40）
3. 用户话术加权：「朋友推荐/群里说/老师带」+1 级；「内幕/稳赚不赔」+2 级；「必涨/翻倍」+1 级。

## 评级
| 命中数(加权后) | 评级 | 输出要求 |
|---|---|---|
| 0-1 | 🟢 未见异常 | 正常分析可继续 |
| 2-3 | 🟡 注意 | 报告头部插入黄色警示 |
| 4-5 | 🟠 警惕 | 警示置顶，建议核实信息源 |
| ≥6 | 🔴 高度可疑 | 终止操作分析，只输出风险报告 |

> 本检测为公开信息排查，不构成任何投资建议。
