# 提问模板 · superyouzi 问句大全

复制粘贴即用。占位符（如「某只股票」「某代码」）替换为你自己的标的。

---

## 一、市场情绪 / 能不能做

```
今天市场情绪怎么样，短线能做吗？
```
```
今天涨停家数和连板高度怎么样，处于什么阶段？
```
```
现在情绪是冰点还是主升，适合进场还是观望？
```
```
今天的打板溢价率和题材聚集度怎么样，风险偏好如何？
```

---

## 二、题材主线 / 板块方向

```
今天有没有明确的主线题材，哪个板块最强？
```
```
当前热门板块是进入反身性加速阶段还是还在形成期？
```
```
今天涨停池的票集中在哪几个方向，主线有没有切换的迹象？
```
```
这个板块的接力机会还有吗，处于扩散期还是尾声？
```

---

## 三、个股分析 / 框架会诊

```
帮我分析一下某代码这只股票，看看处于什么阶段
```
```
某只股票今天跌了很多，是超跌机会还是继续跑？
```
```
某代码最近连续涨停，打板机会怎么看，风险收益比合不合适？
```
```
某只股票趋势上行，现在属于什么位置，能追吗？
```

---

## 四、持仓复核

```
我持有某代码，帮我做个框架会诊，看看还值不值得拿
```
```
某只股票我已经被套了，帮我分析三个情景应该怎么应对
```
```
我的仓位是某代码，现在仓位合不合适，风险在哪里？
```
```
帮我给持仓做个风险复核，重点看下行风险和证伪条件
```

---

## 五、追问模板（让报告更有用）

拿到初步报告后，继续追问：

```
给我一个悲观预案：如果判断错了，止损条件是什么？
```
```
这个判断的证伪条件是什么？出现什么信号说明分析不成立？
```
```
如果要参与，仓位区间建议是多少，上限是几成仓？
```

## 六、深度体检（深研引擎）

```
<某代码> 值不值得长期拿？
```
```
给 <某代码> 这只票做个全面体检
```
```
让评审团全员评审 <某代码>（深度模式）
```
```
<某代码> 这家公司的 DCF 大概什么水平（注：AI 会要求你明示假设，如增速/WACC）
```

---

## 七、风险排查示例

**遇到群里推荐或朋友介绍的票，先查再说：**

```
朋友推荐我买某只股票，群里有人说会涨，帮我查一下这票有没有风险
```

工具会自动触发杀猪盘 8 信号排查，告诉你有没有拉高出货、异常龙虎榜、话术触发等风险特征。

## 八、点名模式（手动指定人物，自动路由之外的玩法）

直接喊名字，让指定的"老师傅"单独出场：

- 用赵老哥的框架看一下 <某代码>
- 让冯柳给 <某代码> 打个分
- 让巴菲特和 Serenity 同时评 <某代码>，我想看分歧
- @体检 <某代码>（等价于深度体检）
- @全员 <某代码>（28 位评审团全员上场，深度模式）
- @查盘 <某代码>（杀猪盘排查）

> 点名模式输出更轻快，但规矩不变：数字带来源、结论带证伪条件、附免责。
