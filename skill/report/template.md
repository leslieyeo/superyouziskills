# 复盘报告模板

所有输出必须套用本模板。硬规则：
- 禁止出现「基本面良好 / 前景广阔 / 值得关注」——出现即重写
- 每条结论必须带【证伪条件】；预案必须给三情景（乐观/中性/谨慎）+ 触发信号
- 每个数字标来源（脚本 source 字段 / 联网搜索出处）；缺失写「数据缺失」，禁止编造
- 页脚免责行固定，不得删改

## 结构
### ① 市场环境卡
今日涨停 N 家 / 最高 N 连板 / 2 连板以上 N 家（来源: panel）→ 环境评级：能做 / 谨慎 / 空仓（依据 Asking 框架阈值）
### ② 主线与题材
板块涨幅榜前 3 + 涨停簇归属 → 主线判断 + 所处反身性阶段（索罗斯框架）
### ③ 个股定位（如有标的）
角色：龙头/中军/补涨/跟风 | 数据底牌：现价、涨跌幅、换手、市值、龙虎榜、资金流（全部带 source）
### ④ 框架会诊
按路由选 2-4 个框架，各自给【判断 + 引用的具体信号 + 证伪条件】，分歧必须呈现，不许和稀泥
### ⑤ 情景预案
乐观（触发信号→应对）/ 中性（…）/ 谨慎（…），各配仓位区间建议
### ⑥ 风险卡
杀猪盘评级（如触发）+ 该股 / 该题材最大的一个风险

### ⑦ 评审团裁决（仅深研模式）
总分大字 + 流派分条（九流派各自均分，缺席流派标「未上场」）+ 最高分评委与最低分评委各一句口吻点评（附其引用的数据）+ 分歧度与解释 + DCF 摘要（每股内在价值/安全边际/关键假设一行列出）
