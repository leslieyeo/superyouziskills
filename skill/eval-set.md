# 评委评测集 v1.0

> 用途：验证各评委框架在典型场景下的分数是否有意义的差异（辨别力自检）。
> 使用方式：给定下方某一场景，让深研模式输出所有评委评分，对照「预期行为」核查结果是否符合预期。

---

## 场景一：经典高质量消费白马（茅台型）

**场景描述**：消费品龙头企业，食品饮料行业，A 股大盘。
**简化数据摘要**：
- `val.pe_percentile_5y`：75%（历史估值偏贵）
- `val.pb`：12 倍
- `finhist.roe_avg_3y`：28%（连续高 ROE）
- `finhist.revenue_yoy`：+15%（稳定增长）
- `panel.top_boards`：无（非题材股）
- `sentiment.grade`：60%（中性偏热）
- `kline.summary.pct_3d`：+2%

**预期行为**：

| 评委 | 预期结果 | 核心原因 |
|------|---------|---------|
| 巴菲特 | 70–80 分 | 护城河明确（品牌 + 定价权），ROE 持续高，溢价合理 |
| 格雷厄姆 | 30–45 分 | PE/PB 严重偏贵，不符合安全边际，数字逻辑打不通 |
| 卡拉曼 | 40–55 分 | 高估值无充足安全边际，但护城河存在，比格雷厄姆略宽松 |
| 芒格 | 75–85 分 | 完美商业模式，高质量管理，护城河极强，比巴菲特更高 |
| 林奇 | 60–70 分 | 消费股能力圈内，增速合理但 PEG 偏高，稍犹豫 |
| 冯柳 | 20–40 分 或 弃权 | 情绪非冷，赔率不够，弱者体系此时不参与 |
| 邓晓峰 | 65–75 分 | 质量认可，但不是困境反转型，给出合理分数 |
| 巴菲特 vs 格雷厄姆 预期分差 | ≥ 25 分 | 核心差异验证 |

**辨别力验收标准**：巴菲特 > 格雷厄姆 ≥ 30 分差；冯柳 < 格雷厄姆（赔率原则）。

## 场景二：A 股超跌小盘（无基本面消息，近 20 日跌幅 -38%）

**场景描述**：中型制造业公司，近 20 日无重大公告，市场情绪导致的无差别下跌。
**简化数据摘要**：
- `quote.change_pct`：当日 -5%
- `kline.summary.pct_3d`：-12%（继续下跌）
- `val.pb`：1.2 倍（历史低位）
- `finhist.revenue_yoy`：+3%（平稳）
- `panel.zt_summary.zt_count`：18（低于均值 40）——恐慌日
- `sentiment.grade`：15%（极度悲观）
- 距 25 日均线乖离率：-22%

**预期行为**：

| 评委 | 预期结果 | 核心原因 |
|------|---------|---------|
| BNF（b-bnf 若存在，否则参考超跌反弹逻辑） | 高分（75+） | 乖离率 -22% 达极值，恐慌背景成立 |
| 小鱼儿 | 60–75 分 | 超跌反弹条件大部分满足，需看企稳信号 |
| 格雷厄姆 | 60–70 分 | PB 1.2 倍接近清算价值，安全边际存在 |
| 巴菲特 | 弃权 或 30 分以下 | 无护城河信息，制造业不在典型能力圈 |
| 米涅尔维尼 | 弃权 | 下跌趋势，无 Stage 2 条件 |
| 索罗斯 | 弃权 或 20 分 | 无叙事可跟踪，反身性框架不适用 |
| 邓晓峰 | 55–70 分 | 困境反转型标的，但需要行业逻辑支撑 |

**辨别力验收标准**：BNF/小鱼儿 vs 米涅尔维尼 预期分差 ≥ 40 分；格雷厄姆 vs 巴菲特分差 ≥ 30 分。

- `finhist.revenue_yoy`：+8%（营收增速一般）

## 场景五：财报质量存疑的成长股

**场景描述**：医疗器械公司，EPS 高增速，但应收账款暴增，经营现金流持续为负。
**简化数据摘要**：
- `finhist.revenue_yoy`：+45%（高增速）
- `val.pe`：80 倍
- `finhist.roe_avg_3y`：15%
- 应收账款占营收比：68%（异常）
- 经营现金流：-2.3 亿（连续 3 年负）
- `kline.summary.pct_3d`：+8%（技术面强势）

**预期行为**：

| 评委 | 预期结果 | 核心原因 |
|------|---------|---------|
| 查诺斯 | 弃权（做空逻辑触发） | 应收账款/现金流异常，财报质量信号最强烈 |
| 格雷厄姆 | 15–30 分 | 现金流为负，账面数字无法验证真实盈利 |
| 林奇 | 30–50 分 | PEG 高且现金流存疑，但增速吸引，犹豫状态 |
| 欧奈尔 | 55–70 分 | EPS 增速 45% 满足 C 条件，技术面强，按系统执行 |
| 冯柳 | 弃权 或 20 分 | 情绪偏热，财报质量存疑时不参与 |
| 马克斯 | 30–40 分 | 风险第一，现金流为负是大风险，不看增速 |
| 巴菲特 | 弃权 | 医疗器械不在典型能力圈，且财报有疑 |

**辨别力验收标准**：欧奈尔 vs 格雷厄姆 ≥ 30 分差（两套系统对同一票的系统性差异）；查诺斯必须弃权并注明空头逻辑。

## 使用方式

1. 选择一个场景，用该场景的数据喂给深研模式
2. 收集所有 28 个评委的输出评分
3. 对照上方「预期行为」核查：
   - 该弃权的有没有弃权（弃权条件验证）
   - 同流派内差异是否存在（辨别力验证）
   - 跨流派的分数方向是否符合各自哲学（一致性验证）
4. 如果某个评委的表现不符合预期，回对应 `jury/*.md` 文件检查 `rubric` 和 `弃权条件` 的写法

## 常见失效模式

| 失效表现 | 可能原因 | 修复方向 |
|---------|---------|---------|
| 巴菲特和格雷厄姆给出接近分数 | 护城河/安全边际区分度不够 | 加强 a-buffett 的 ROE 权重，a-graham 的 PE/PB 硬门槛 |
| 冯柳从不弃权 | 弃权条件写得太模糊 | 把 `sentiment.grade > 70%` 写进弃权条件作为硬触发 |
| 格雷厄姆给亏损公司高分 | rubric 没有盈利硬门槛 | 在 rubric 中加"亏损直接 0 分"条款 |
| 所有评委场景五都给高分 | 财报质量维度权重不足 | 确认各评委 rubric 是否有现金流/应收账款维度 |
