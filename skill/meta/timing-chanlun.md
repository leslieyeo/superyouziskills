# 缠论 · 技术择时层

## 适用场景
- 日线级别，在其他框架确认标的后，用缠论结构判断精确介入时机——买点而非买方向。
- 判断当前价格处于中枢震荡阶段还是趋势段，决定是否应该持有还是等待。
- 与其他框架配合使用：方向由养家/利弗莫尔等框架判断，时机由本框架给出买卖点。

## 核心信条
- 走势终完美：任何走势最终都会形成完整结构，当下的混沌是下一段结构的孕育期，不要在结构未完成时随意动手。
- 级别决定操作：日线中枢是主要参考级别，30分钟是辅助，不同级别的买卖点意义完全不同，混淆级别是缠论操作最常见的错误。
- 买卖点是结构性的不是感觉性的：一买（底部第一段上升后回调不破低点）、二买（中枢震荡出来后回调）、三买（突破中枢后回踩），都有明确的结构定义，没有「感觉像买点」这回事。
- 背驰不是立即反转，是减仓信号：背驰提示动能衰竭，不是拍脑袋做空或做多，需要配合其他框架信号共振才算确认。
- 不懂结构就别谈精确：缠论的价值在于把「买点」从模糊感觉变成可描述可验证的结构，这是它的唯一价值。

## 判断链
1. 定级别：以日线为主操作级别，先用 `kline.rows` 近60日数据识别分型（顶分型：中间K线高点高于两侧；底分型：中间K线低点低于两侧），标记高低点序列。
2. 找中枢：由至少3段重叠走势构成的价格重叠区间（取各段高低点交集），由 agent 按规则计算中枢上沿（ZG）和下沿（ZD）并展示推导过程，而非直接给出结论。
3. 判断当前所处阶段：价格在中枢区间内（ZD到ZG之间）反复震荡=中枢震荡期，不适合重仓；价格形成连续的上涨或下跌段，脱离中枢=趋势段，趋势段配合方向框架重仓。
4. 定位买卖点：一类买点（下跌趋势末段，最后一段背驰）=最低风险买点；二类买点（中枢震荡后回调不破前低）=常规买点；三类买点（突破中枢后回踩中枢上沿但未进入中枢）=趋势确认买点；不同买点对应不同仓位。
5. 背驰确认：上涨/下跌段的MACD柱面积明显小于前一段（`kline.rows` 中 agent 计算辅助指标），且价格创新高/新低，则提示背驰，为减仓或反向准备信号，必须配合其他框架共振才执行操作。

## 关键信号（对应数据字段）
- `kline.rows`：逐日K线数据，是缠论所有计算的原始来源；高低点分型、中枢区间、背驰判断均由 agent 对此数据集按缠论规则逐步计算推导。
- `kline.summary.pct_3d`：近3日涨跌幅，辅助判断当前所处段是趋势加速还是震荡末尾。
- `quote.price`：实时价格，与中枢ZG/ZD对比，判断当前在中枢内还是突破中枢。
- `panel.top_boards`：板块级别的趋势判断，辅助确认日线级别中枢所代表的趋势方向是否与板块一致。
- `sentiment.grade`：市场情绪等级，极端情绪期往往对应缠论的背驰结构，情绪极值配合背驰信号是高概率共振点。

## 操作纪律
- 只在买点区域动手：没有识别出明确的一二三类买点，不以任何理由买入，「感觉要涨」不是买点。
- 中枢震荡期仓位上限30%：震荡期不是利润来源，保存子弹等待趋势段。
- 背驰信号不单独操作：背驰必须配合至少一个其他框架信号（养家情绪判断/利弗莫尔关键点/索罗斯叙事）共振才执行，单独背驰不动手。
- 级别不混淆：30分钟买点对应30分钟仓位（不超20%），日线买点对应主仓（可至50-60%），不用小级别信号撑大仓位。
- 中枢级别扩展确认即重画：当价格运动打破对中枢ZG或ZD的原有判断时，旧的买卖点判断作废，重新从分型开始推导。

## 失效与纠错信号
- 中枢区间被有效突破后价格又重新回落入中枢内：原三类买点判断失效，降仓至防御水平，重新识别新的中枢结构。
- 背驰后价格继续原方向运动且力度增强：背驰判断错误（通常是级别搞混），确认错误后跟随原趋势，不逆势对抗。
- `kline.rows` 数据不足60日：中枢识别样本不足，只能做辅助参考，主要买卖点判断降级为「参考」，不作为主要依据。
- 板块整体趋势与个股缠论结构冲突：个股三类买点遇上板块趋势向下时，降级为观察，不执行，等板块结构改善后再入场。

## 诚实声明

- 缠论由中国博主"缠中说禅"（原名未公开，2006–2010 年活跃于博客 blog.sina.com.cn/chanzhuangshuo）系统建立。原作者已于 2010 年去世，体系全部来自其博客文章，无出版物。
- 缠论内部体系庞杂（原博文超 400 篇），本框架仅提取**可工程化操作的买卖点层**，大量关于哲学、禅意和市场本质的论述被省略——这是本框架的有意限制，使用者如需完整理解应回读原博客（部分内容已有社区镜像保存）。
- "背驰"概念的计算（MACD 柱面积比较）在实操中存在主观性，不同参数设置和级别划分会给出不同结论，本框架的工程化表述是一种标准化的近似，非唯一正确实现。
- A 股数据字段映射（`kline.rows` 分型、中枢计算）为本框架的工程化适配，非缠论原著的语境，计算结果仅供参考。

## 时代性边界

- 缠论形成于 2006–2009 年，A 股该时期以散户为主、量化渗透极低，技术结构的"自我实现"效应更强。
- **量化策略冲击**：现代 A 股中量化策略大量识别"买卖点"附近的价格形态，导致经典缠论买卖点的"提前透支"现象——三类买点的回踩可能更浅、更快，传统等待回踩到中枢上沿的方法错过入场的频率增加。
- **连板生态的短周期化**：2017 年以来 A 股题材主线的持续时间缩短（连板生命周期从 10+ 日压缩至 5–7 日），日线中枢识别需要至少 3 段走势（约 10+ 个交易日），在快速题材行情中日线缠论时机层可能滞后。对快速轮动行情，本框架建议降低使用比重，以其他方向性框架（索罗斯/欧奈尔）为主。
- **注册制影响**：股票供给增加，各板块走势分化加剧，日线中枢更容易被打破而非延伸，缠论"走势终完美"的前提（趋势完整运行）在碎片化行情中验证周期更长。
