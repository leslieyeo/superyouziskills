# superyouzi 蒸馏质量规范 v1.0

> 适用范围：`frameworks/`（13 套人物框架）+ `meta/`（缠论、西蒙斯元框架）的交易框架文件 + `jury/` 的评委档案文件。（`risk/` 下的风险教育文件参照本规范精神但豁免引用计数要求，详见各文件内诚实声明。）
> 本规范是 persona-distill skill 的轻量适配版，针对"有限场景调用"（打分/判断链）而非"通用人格复现"。

---

## 一、为什么需要这套规范

jury/framework 文件的调用场景高度固定：给定一只股票的数据字段，评委按自己的 rubric 打分并说一句点评。这不需要完整人格档案，但需要**辨别力**——同流派四个评委打出来的分数必须有差异，且差异可以被解释。

没有辨别力的框架 = 换了个名字的通用量表，深研模式信息量归零。

---

## 二、两类文件的最低标准

### 2A · 交易框架文件（`frameworks/`）

交易框架是实操判断链，调用频率最高。要求更严。

| 元素 | 最低要求 | 说明 |
|---|---|---|
| **原话引用** | ≥ 5 条，带出处 | 出处格式：平台/书名 + 日期/章节，URL 优先 |
| **来源类型** | ≥ 2 种不同来源 | 不能全是同一平台/书；交叉校验降低引用错误风险 |
| **诚实声明** | 必须有 | 注明哪些是本人自述未审计、哪些经第三方确认、哪些是工程化推导 |
| **失效场景** | ≥ 2 条 | 具体情境下框架判断会失效，给出信号和应对 |
| **时代性边界** | 至少 1 条 | 市场环境变化（注册制、量化比例等）对框架的影响 |
| **一句话口令** | 必须有 | 蒸馏出的核心判断逻辑，供快速记忆 |

**国内匿名游资额外要求**：优先引用淘股吧/雪球原帖（带 URL）；实盘数据要注明来源可信度等级（官方审计 > 第三方统计 > 本人自述）。

**国际公开人物额外要求**：优先引用著作原文或官方采访；不得只引用"他说过"的网络流传版本，须回溯到原始载体。

---

### 2B · 评委档案文件（`jury/`）

评委只在深研模式调用，频率低于框架，但辨别力要求更高——28 人打同一只票，结果必须有意义的分散。

| 元素 | 最低要求 | 说明 |
|---|---|---|
| **弃权条件** | 必须有，≥ 3 条 | 明确说清"什么标的/情境这个评委整体不参与打分" |
| **原话引用** | ≥ 3 条，带出处 | 体现其独特视角，不是大众都知道的那种共识 |
| **同流派差异说明** | 必须有 | 与同一流派其他评委的核心差异是什么（避免同质化）|
| **典型表达句式** | ≥ 3 条 | 调用时口吻/语言风格的参考锚点 |
| **rubric 分维度** | 合计权重 = 100，维度 ≥ 4 | 每个维度有明确的数据字段对应或评估依据 |
| **诚实声明** | 必须有 | 注明框架依据的资料类型和局限 |

## 三、弃权条件写法规范

弃权条件是 jury 文件中最容易缺失、影响最大的元素。写法要求：

```markdown
## 弃权条件
以下情境本评委整体不参与打分（分数栏留空，理由注明）：
- [具体情境]：[原因，链接到其投资哲学]
- [具体情境]：[原因]
- [具体情境]：[原因]
```

**好的弃权条件**（可操作、有哲学依据）：
> "近 5 年无连续盈利记录：格雷厄姆的安全边际建立在有历史数据可验证的基础上，没有盈利历史等同于没有定价锚点。"

**差的弃权条件**（模糊、无法操作）：
> "标的质量太差时弃权。"

## 五、质量自检清单

改完一个文件后，对照以下清单：

```
[ ] 原话引用 ≥ 要求条数，每条有出处
[ ] 弃权条件已写（jury 文件必须）
[ ] 同流派差异说明存在（jury 文件必须）
[ ] 失效场景 ≥ 2 条（framework 文件必须）
[ ] 诚实声明存在，注明了资料局限
[ ] 一句话口令存在（framework 文件必须）
[ ] rubric 维度权重合计 = 100（jury 文件必须）
[ ] 典型表达句式 ≥ 3 条（jury 文件必须）
```

## 六、不需要做的事

- **不需要**跑完 persona-distill 的 7 阶段流程
- **不需要** 30 条以上原话样本（30 条是通用人格蒸馏的要求，jury 场景 3-5 条已够）
- **不需要**建完整的 `references/research/` 目录（除非框架本身打算升级为完整 mind 文件）
- **不需要**红队测试（用"同流派对照"替代：打出来的分数有无差异即可自检）
