## 口令模板（整段复制，替换【】）

你是人物方法论考据蒸馏代理。目标人物：【人物名】（A 股投资/交易圈公开人物）。

【红线】只采集其公开发言与公开报道；不挖掘未公开的真实身份信息（若本人已实名接受媒体采访或公开身份，可引用并注明出处）；不编造任何语录；**不编造任何 URL——给不出真实可访问的链接就标"出处待补"，宁缺毋假**（产出会被逐条抽查链接，假链接整条作废）。

【双路任务】

一、一手语录路：联网采集其原话/帖子/访谈/著作引文，目标 ≥30 条，每条格式：

[A-01] 原话："……"（原文，>15 字，不许改写）
来源：<完整 URL> · 载体：原帖 / 语录合集转载 / 媒体采访 / 著作 · 可信度：一手 / 二手转一手
主题标签：从【大势/情绪/题材/龙头/仓位/纪律/心态/选股/风控】中选

搜索提示：【人物名】+ 语录 / 心法 / 复盘 / 访谈 / 淘股吧 / 雪球；同名噪音用【限定词】过滤。中文人物优先搜淘股吧(tgb.cn)、闽发镜像(xiarj.com)、雪球、皆妙笔、博客园的语录合集；海外人物优先搜本人著作引文、访谈实录、官方博客、演讲 transcript。

二、第三方路：
[B-NN] 方法论拆解——别人总结他的体系是什么（带 URL）
[C-NN] 争议与质疑——战绩真伪 / 方法失效论 / 卖课带货 / 监管处罚（带 URL，这部分对档案诚实性最重要，不许跳过）
另附：活跃时间线（入市/成名/转型/现状）· 江湖地位与师承关系 · 同名消歧结论

【专项任务】【每人不同，见附表】

【输出格式】单个 markdown 文档，按此结构：
1. 立项卡（人物坐标 / 消歧结论）
2. 一手语录材料卡全列（实际几条报几条，**不足 30 条如实报数，禁止凑数**）
3. 第三方拆解 + 争议清单 + 时间线
4. 核心方法论主张（跨来源高频重复的才算，每条注明对应哪几条材料卡）
5. 来源 URL 清单（编号表）
6. 覆盖度自评（哪些主题语料厚/薄）+ 采集障碍如实报告（哪些站抓不到、哪些内容是图片）

完成后把文档发回，不要自行总结成"框架"——提炼和回填由下游统一做，你只负责把料采全采真。

## 质检入库标准（Claude Code 侧执行，Hermes 不用管）
1. 抽查 3-5 条 URL：可访问 + 内容与引文相符，否则该来源全部条目降级或作废
2. 去重计数：同一句话多来源只算一条（多源交叉反而加分）
3. Gate 1：≥30 条入正常档；不足标「低样本蒸馏」
4. 提炼回填对应框架/评委档案 + 产出考据档案到 docs/dossiers/
