## 三、高频核心主张

### 交易理念
1. **"击鼓传花"论**：股票自身没有使用价值，游资操作是在短期内快速完成大量筹码交换，完成财富重新分配
2. **交易对手方思维**：每一次买入都想到交易对手方是谁，目标客户是谁
3. **"围着主线做"**：多研究龙头，研究涨停，不断积累总结反思等待进阶
4. **涨停效率论**：做涨停更有效率更确定
5. **仓位即一切**：深刻理解仓位二字是理解大资金行为逻辑的开始

### 风控原则
1. **小资金以攻代守**：行情好赚钱时拼命赚，不控仓回撤必然大
2. **熊市比稳不比快**：需要有发现确定性机会的能力(概率+实效性+高盈亏比)
3. **杂毛屏蔽**：短线乱打是回归赤贫的捷径
4. **行情不好≤1/10仓位**：极度保守的风控纪律
5. **满仓出击要有确定性**

### 战法体系
1. **一字三板战法(独创)**：排连续一字涨停的第三个涨停——前1/2板无分歧难买到，三板是小分歧点，获利盘有卖冲动
2. **连板战法(主力手法)**：占比从50%→90%+，由慢连板→快连板，由低位→中高区域
3. **反包战法**：涨停→调整→再涨停，最好叠加热点+直线分时，"涨停跌停涨停"模式最佳
4. **大资金承载票**：逻辑要绝对主流，成交要大
5. **低吸是应市场而生**：顺着市场节奏低吸绝对热门股

### 进化观
1. **"悟道"**：对市场有很好认知，能持续赚钱，虽有反复但能及时控制
2. **资金体量驱动进化**：1000万以下分仓做不需考虑生态；亿级资金需要理解席位博弈/承接/切换
3. **从技术到逻辑**：情绪博弈越来越需要结合股票内在价值
