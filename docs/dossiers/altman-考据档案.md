# Sam Altman 考据档案

**人物坐标**: OpenAI CEO（2019 至今，2023-11 被罢免后 2023-11-22 回归）。1985 年生于芝加哥。斯坦福大学计算机科学专业，两年后退学。Loopt 联合创始人（2005，社交定位 App，2012 被 Green Dot 以约 4300 万美元收购）。Y Combinator 总裁（2014-2019）。OpenAI 联合创始人（2015）。

**核心判断模型**（带原话）

1. **事件视界宣言**: 「我们已经越过事件视界；起飞已经开始。」("We are past the event horizon; the takeoff has started." — "The Gentle Singularity"，2025-06-10) 这是他对当前 AI 渗透率位置的判断：不再是"是否会发生"，而是"已经在发生"。

2. **指数曲线人生观**: 「你自己也要成为一条指数曲线——你应该让你的人生追随一条持续上升、向右上扬的轨迹。」("You also want to be an exponential curve yourself." — "How To Be Successful"，2015) 选公司的逻辑与选人相同：看曲线形态，不看当下快照。

3. **算力货币论**: 「我认为算力将成为未来的货币。」("I think compute is going to be the currency of the future." — Lex Fridman #419，2024-02) 对应选股逻辑：算力供给扩张是 AI 受益方空间的前置变量。

4. **超级智能时间线**: 「我们有可能在几千天内就拥有超级智能（！）。」("We will have superintelligence in a few thousand days." — "The Intelligence Age"，2024-09) 争议：Grady Booch 等批评者认为此预言服务于融资叙事而无现实依据，应折价使用。

5. **渐进主义双轨叙事**: 「会有很艰难的部分，比如整类工作消失，但另一方面世界将变得如此富裕、如此迅速……」("The Gentle Singularity"，2025-06) 他技术预测激进，社会变革预测温和——「大多数工作的变化比大多数人预期的要慢」。

**诚实边界**
- 他不是职业投资人，未对 A 股个股公开表态，本档案的选股 rubric 是其方法论的迁移应用。
- OpenAI 从非营利到 PBC 转型过程中的治理争议（C-01，C-03）显示公开叙事与机构行动之间存在张力。
- "few thousand days" 超级智能预测被批评为融资驱动，量化预测成分需与方法论判断逻辑分开使用。
- 2026-05 CBA 访谈他已自我修正：「我原以为到现在初级白领岗位被淘汰的影响会比实际发生的更大。」
