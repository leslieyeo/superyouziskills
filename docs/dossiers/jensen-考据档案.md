# 黄仁勋 (Jensen Huang) 考据档案

**人物坐标**: NVIDIA 联合创始人、总裁兼 CEO（1993 至今）。1963 年生于台北，台湾裔美国人。俄勒冈州立大学电气工程学士，斯坦福大学电气工程硕士（1992，在职）。AMD 和 LSI Logic 工程师出身，1993 年在 Denny's 餐厅与两位同事共同创立 NVIDIA。

**核心判断模型**（带原话）

1. **Token 工厂经济学**: 「输入是电子，输出是 token。中间是 NVIDIA。」("The input is electrons, the output is tokens. In the middle is NVIDIA." — GTC San Jose 2026) 一切产业判断的底层框架：谁控制转化效率中间层，谁收取算力租金。

2. **供给稀缺测试**: 「如果 GPU 租赁价格保持高位，就没有泡沫。」(Davos 2026，Fortune) 他用租赁价格而非 PE 判断泡沫，可操作化程度高。

3. **生态护城河优先**: 「我们拥有最大的合作伙伴生态系统……这是我们可以做到而别人很难复制的事情之一。」(Dwarkesh Podcast，约 2026-04) CUDA 20 年积累是他自己识别护城河的参照系。

4. **AI 基础设施量级**: 「分析师预测超大规模资本支出将在 2027 年超过 1 万亿美元，AI 基础设施支出有望在本十年末达到每年 3 至 4 万亿美元。」(GTC 2026) 争议：共识预期约为其预测的 1/3 至 1/4，需持怀疑。

5. **战略投资逻辑**: 对 Anthropic、OpenAI、Mistral 等的投资定性为「扩大 NVIDIA CUDA AI 生态，使每个模型都能在 NVIDIA 平台上实现最优运行」(Q3 FY2026 财报电话)，资本服务于生态绑定而非财务回报。

**诚实边界**
- 他是"卖方 CEO"，所有产业预测具有商业推广属性。
- $3-4 万亿/年指引被 Needham 分析师 Laura Martin 认为是共识预期的 3-4 倍，24 个月以上的预测应持保留。
- 训练芯片护城河是否延续到推理/Agent 时代存在真实争议（CNBC 专栏，2026-03-19）。
- 中国芯片出口管制问题上存在明显利益冲突，其表态需折价。
